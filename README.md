## 🎯 Core Purpose

*   **Bridging Information Asymmetry:** Translates traditional artistic talent into modern corporate roles (e.g., UI/UX, 3D asset modeling, character design), giving regional educators real-time industry leverage to present creative pathways to students and parents.
*   **B2Institution Focus:** Shifts the career guidance model from volatile teenage mindsets to continuous profiling and enhancement of educator empathy, adaptability, and psychological readiness.
*   **Regional & Vernacular Inclusivity:** Specifically targets the Telangana education ecosystem, empowering teachers to guide tier-2 and tier-3 students who possess strong heritage art skills (e.g., Cheriyal painting) but lack corporate design jargon or English fluency.

## ✨ Standout Application Features

*   **Zero-Latency SPA Architecture:** Built with Vanilla JavaScript (ES6+) and Tailwind CSS, featuring responsive mobile layouts and an aggressive state-preservation engine that prevents data loss during backward and forward section navigation.
*   **Bilingual Text-to-Speech (A11y):** Powered by the native browser Web Speech API, offering dual English (en-IN) and Telugu (te-IN) audio options with contextual, screen-reader style voice guidance based on question type.
*   **Anti-Bias & Ethical Consent Engine:** Uses Fisher-Yates choice shuffling to eliminate top-option selection bias, paired with an autonomous Yes/No research consent pipeline that triggers a dynamic feedback modal if consent is declined.
*   **Automated Data & PDF Pipeline:** Asynchronously logs entries via Google Apps Script into Google Sheets, formatting multi-select answers into line-broken bulleted lists (•) and automatically dispatching generated PDF summaries to opted-in users.

## 🚀 Getting Started

Because this project utilizes a pure, dependency-free architecture, setup is completely frictionless.

1.  Clone the repository to your local machine.
2.  Open `index.html` directly in any modern web browser.
3.  No build steps, package managers, or local servers are required.
